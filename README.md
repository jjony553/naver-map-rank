# 플레이스 랭크 · 파이썬 간편 실행 버전

네이버 지도에서 식당의 키워드별 **일반 순위와 광고 순위**를 따로 확인하는 대시보드입니다. 대량 키워드 입력, 순위 추이·도넛 차트, CSV 가져오기·내보내기와 PDF 인쇄를 제공합니다.

## 가장 쉬운 실행 방법

1. **`시작하기.cmd`를 더블클릭하세요.**
2. 처음에는 필요한 파이썬 패키지를 자동으로 설치합니다. 설치된 Edge/Chrome을 사용하며, 브라우저가 없을 때만 Chromium을 설치합니다.
3. 브라우저에 화면이 열리면 **매장 등록 → 키워드 붙여넣기** 후 기기 탭에서 PC 또는 모바일 웹을 선택하고 **순위 측정 버튼**을 누르세요.

Python 3.10 이상이 필요합니다. 설치되어 있지 않으면 [Python 공식 다운로드](https://www.python.org/downloads/)에서 설치하고 ‘Add Python to PATH’를 선택하세요. Node.js와 npm은 필요하지 않습니다.

실행 중인 검은 창은 열어 두세요. 종료하려면 창에서 `Ctrl+C`를 누릅니다. 다시 사용할 때도 같은 파일을 더블클릭하면 됩니다. 주소는 [http://127.0.0.1:4173](http://127.0.0.1:4173)입니다. 이미 실행 중이면 해당 화면을 다시 엽니다.

## 언제 측정하나요?

**선택한 기기의 순위 측정 버튼을 누른 시점부터** 키워드를 순서대로 조회합니다. 자동 예약 측정은 포함하지 않습니다. 여러 키워드를 붙여넣을 수 있고 중복은 자동으로 정리합니다. 최대 1,000개를 등록하며 조회 중 진행 상황과 중단 버튼을 제공합니다. 체크박스로 선택한 키워드만 다시 측정할 수도 있습니다.

**PC / 모바일 웹 탭**으로 결과를 전환합니다. 일반 순위·광고 순위·추이는 기기별로 따로 저장합니다. PC 결과를 모바일 결과로 복사하지 않습니다. 각 탭에서 한 번씩 측정하세요. 상단 **검색 지역 · 변경**에서 기준 지역도 선택할 수 있습니다. CSV 내보내기는 현재 선택한 검색 지역의 두 기기 데이터를 포함하고, 인쇄/PDF는 현재 선택한 기기를 기준으로 작성합니다.

모바일 측정은 모바일 사용자 에이전트·터치·화면 크기를 설정한 **모바일 웹 에뮬레이션**으로 `m.map.naver.com`의 공개 검색 결과를 읽습니다. 실제 휴대폰 네이버 앱을 조회하는 방식이 아닙니다. 현재 모바일 웹 화면의 제공 범위는 최대 75개이며, 100위를 요청해도 75개만 확인했다면 75개 범위의 관측으로 기록합니다.

로컬 화면은 처음에는 빈 실제 측정 화면으로 시작합니다. 온라인 시연 화면의 ‘성수온실’ 수치는 명확히 표시된 샘플입니다. 내 매장을 처음 등록하면 샘플 키워드는 제거되고 직접 키워드를 입력합니다.

## 순위 해석

- **일반 순위:** 광고 카드를 제외한 일반 검색 결과 내 순번입니다. 광고를 중단했을 때의 예상 순위가 아닙니다.
- **광고 순위:** 관측된 광고 카드 사이의 순번입니다. ‘광고 미노출’은 조회 범위 안에서 광고를 발견하지 못했다는 뜻이며, 광고 집행 여부를 단정하지 않습니다.
- **미노출과 오류:** 실제 확인한 범위 안에서 찾지 못한 경우만 미노출입니다. 차단, 보안 확인, 연결 실패는 오류로 표시하며 순위를 생성하지 않습니다.
- **조회 환경:** PC 또는 모바일 웹·선택한 검색 지역과 좌표·조회 시각·관측 범위를 기록합니다. 환경 메모 입력은 검색 위치와 별개의 기록입니다. 네이버 기본 위치, 시각, 개인화 등에 따라 결과가 달라질 수 있습니다.
- **조회 범위:** PC는 일반 결과 최대 100위까지 요청합니다. 현재 모바일 지도 웹은 최대 75개 결과를 제공하며, 키워드에 따라 더 적을 수 있습니다. `maxDepth`와 `observedDepth`는 실제 관측 수이며 `requestedDepth`는 요청 범위입니다.

매장명만으로 지점을 혼동하지 않도록 네이버 지도 상세 URL 또는 플레이스 ID로 구분합니다. `naver.me` 단축 링크는 브라우저에서 펼친 뒤 전체 URL을 붙여넣으세요.

## GPS 위치에 따라 순위가 달라지나요?

네. 이용자 위치, 검색어에 포함된 지역명, 보고 있는 지도 범위와 조회 환경에 따라 일반 결과와 광고 노출 순위가 달라질 수 있습니다. PC 지도는 IP를 바탕으로 접속 위치를 예측한다고 네이버가 안내합니다. GPS 하나로 순위가 결정되는 것은 아닙니다.

상단 **검색 지역 · 변경** 또는 **수집 설정**에서 지역을 설정할 수 있습니다.

- **시·도 → 시·군·구 선택:** 예를 들어 경기도 → 수원시, 서울특별시 → 강남구처럼 고르면 됩니다. 전국 행정구역과 일반구가 있는 시의 시 단위 선택을 지원합니다.
- **지역 이름 검색:** `수원`, `경기 수원`, `부산 해운대구`, `충남 천안`처럼 입력한 뒤 검색 결과를 선택하세요. 위치는 앱이 자동으로 처리합니다. 위도·경도 입력은 필요하지 않습니다.
- **이전에 선택한 지역:** 기존 측정 지점과 기록도 원래 위치 그대로 다시 선택할 수 있습니다.
- **네이버 기본 위치:** 좌표를 지정하지 않고 네이버 기본 검색 환경을 사용합니다.

지역을 선택하면 앱이 해당 지역의 대표 위치를 자동으로 찾아 조회 중 네이버에 전달합니다. PC는 공개 지도의 검색 중심점, 모바일은 네이버 웹의 ‘내위치’ 기능에 브라우저 기준 좌표를 적용합니다. **네이버 검색 요청·화면이 해당 좌표를 실제 반영했는지 확인한 후에만** 성공 결과를 기록합니다. 반영을 확인할 수 없으면 오류로 처리합니다.

지역별로 PC·모바일 결과와 이력을 따로 보관합니다. 다른 지역으로 바꾸면 그 지역 기록을 불러오거나 새 측정 대기로 표시합니다. 이전 지역으로 돌아가면 기존 결과를 다시 볼 수 있습니다. 매장을 변경하면 모든 지역의 측정값이 초기화됩니다. 키워드 추가·삭제는 전체 지역에서 공유합니다.

실제 기기의 GPS를 읽거나 운영체제 위치를 바꾸지는 않습니다. 또한 접속 IP·광고 타기팅·로그인 개인화까지 해당 지역의 실제 기기와 같아지는 것은 아닙니다. **환경 메모는 실제 검색 지역 설정과 별개**입니다. 모바일 에뮬레이션은 실제 휴대폰 네이버 앱과 환경이 다를 수 있습니다. 조회 조건을 비교할 때 키워드·기기·시각·접속 환경을 함께 확인하세요. 화면의 위치 안내에서도 이 기준을 볼 수 있습니다.

공식 안내: [지도 검색 기준](https://help.naver.com/service/30026/contents/20411?lang=ko&osType=COMMONOS), [PC 접속 위치](https://help.naver.com/service/5637/contents/19945?lang=ko&osType=PC), [광고 노출 조건](https://help.naver.com/service/30026/contents/25605?lang=ko).

지역 목록은 기상청의 **2026-07-01 동네예보 지점 자료**를 기준으로 구성했습니다. 시·군·구 대표 지점을 사용하며, 여러 일반구가 있는 일부 시는 구 대표점의 평균을 시의 기준점으로 사용합니다. 행정구역 전체의 검색 결과를 합산하는 방식은 아닙니다. 원본과 재현 스크립트는 `data/sources/`와 `scripts/build_regions.py`에 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `시작하기.cmd` | 윈도우 더블클릭 실행 |
| `launcher.py` | 전용 환경·의존성 준비와 브라우저 자동 열기 |
| `app.py` | Python Flask 웹 서버와 조회·중단 API |
| `locations.py` | 지역 데이터와 조회 위치 검증 |
| `dist/regions.json` | 공식 원본에서 만든 전국 시·도/시·군·구 목록 |
| `collector.py` | Python Playwright로 네이버 지도 공개 화면 관측 |
| `requirements.txt` | Python 패키지 목록 |
| `dist/` | 기존 디자인을 유지한 HTML·CSS·브라우저 JavaScript |

화면의 JavaScript는 브라우저에서 동작합니다. 서버와 순위 수집은 모두 Python입니다. 패키지는 프로젝트의 `.venv/`에 설치하며 시스템 파이썬 환경과 분리합니다.

## 명령어로 실행할 때

```powershell
python launcher.py
```

설치만 하려면 `python launcher.py --prepare-only`, 브라우저를 자동으로 열지 않으려면 `python launcher.py --no-browser`를 사용합니다. 포트가 사용 중이면 `python launcher.py --port 4174`로 실행하세요. 로컬 화면은 현재 포트의 수집기에 자동으로 연결합니다.

수동 설치가 필요한 경우:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Edge/Chrome이 없으면 `.\.venv\Scripts\python.exe -m playwright install chromium`으로 브라우저를 설치할 수 있습니다.

## 확인 및 보관

Python 테스트: `.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"`.

온라인 [시연 사이트](https://place-rank-studio-1106.klassicdev.chatgpt.site)는 기존 대시보드를 제공합니다. 실제 Python 수집기는 내 PC에서 실행합니다. 게시된 사이트에서 로컬 수집기로의 접근은 브라우저 정책에 따라 제한될 수 있어, 더블클릭으로 열린 로컬 화면을 사용하는 편이 간단합니다.

CSV에는 선택 지역의 위도·경도·적용 확인 여부를 함께 내보냅니다. CSV/JSON 가져오기는 한 파일에 한 검색 지역만 허용하며, 여러 지역은 파일을 나눠 가져옵니다. 좌표가 없는 기존 파일은 네이버 기본 위치 기록으로 가져옵니다.

측정 데이터와 이력은 해당 브라우저의 로컬 저장소에 보관합니다. 중요한 결과는 CSV로 내보내세요. 브라우저 데이터를 지우면 저장된 이력도 사라집니다. 기본 서버는 `127.0.0.1`에서만 실행됩니다.

구현 참고: [Flask 설치 문서](https://flask.palletsprojects.com/en/stable/installation/), [Playwright Python 문서](https://playwright.dev/python/docs/intro), [네이버 지역검색 API](https://developers.naver.com/docs/serviceapi/search/local/local.md). 네이버 지역검색 API의 업체 목록을 지도 실제 순위로 바꾸어 사용하지 않습니다. 네이버 화면 구조가 변경되면 `collector.py`의 관측 선택자를 조정해야 할 수 있습니다.
